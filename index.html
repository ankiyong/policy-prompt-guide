HOW TO USE
이렇게 사용하세요.

    
  1. 공통 지침부터 시작하기
    공통 지침은 추가 입력 없이 복사해 AI 대화에 한 번 입력합니다.
  2. 항목을 입력하고 프롬프트 생성하기
    카드를 열고 항목별 입력창에 내 생각과 자료를 적습니다. ‘프롬프트 생성’을 누르면 기존 템플릿에 입력 내용이 반영됩니다.
  3. 완성된 프롬프트 복사하기
    결과를 확인하고 ‘프롬프트 복사’를 눌러 같은 AI 대화에 붙여 넣습니다. 입력을 수정했다면 다시 생성하세요.
  4. 내가 판단한 뒤 다음 단계로
    AI의 답변을 확인하고 선택·수정한 내용과 이유를 남깁니다. 다음 단계 카드는 직접 선택하세요.

    
입력 예시
관심 있는 업무·정책: 청년 지원사업 모집공고의 신청정보 안내

    
‘자료 수집 및 분석’은 3개, ‘최종 검토 및 수정’은 2개의 프롬프트를 순서대로 사용합니다. 자료의 원문을 읽고 판단하는 활동은 수강생이 직접 진행합니다.

    
입력 내용은 현재 페이지 안에서만 유지되며 새로고침하거나 페이지를 닫으면 초기화됩니다. 양식 입력창에는 양식 내용이나 파일명을 적고, 실제 파일은 AI 대화에 직접 첨부하세요. ‘전체 프롬프트’ 다운로드는 입력 전 기본 템플릿입니다.
